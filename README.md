# Botones Rápidos

App de Android que agrega hasta 5 botones personalizables al Centro de Control
(Quick Settings). Cada botón tiene nombre, icono y una acción: abrir una app,
abrir un enlace, llamar, abrir un chat de WhatsApp o prender la linterna.

No pide ningún permiso especial.

## Obtener el APK (sin instalar nada en la PC)
1. Crea un repositorio en GitHub y sube todo el contenido de esta carpeta.
2. Entra a la pestaña **Actions** → "Compilar APK" (corre solo al subir).
3. Cuando termine (≈3 min), abre la ejecución y descarga **BotonesRapidos-APK**.
4. Descomprime, instala `app-debug.apk` (permite "instalar apps desconocidas").

## Con Android Studio
Abre la carpeta, espera la sincronización y pulsa Run.

## Usarlo
1. Abre la app, configura un botón y toca **Guardar**.
2. Centro de Control → lápiz (editar) → arrastra "Botón 1…5" al panel.
